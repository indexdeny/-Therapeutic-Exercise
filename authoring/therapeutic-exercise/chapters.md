# Карта уроков — Kisner & Colby, *Therapeutic Exercise*, 7-е изд.

Статусы: `planned` → `ready` (собран и прошёл проверку) → `user-approved`.
«PDF стр.» — номера страниц PDF (страница книги = PDF − 34). Текст: `books/therapeutic-exercise/pages/bookNN/text.md` (NN = номер главы), страницы размечены `## page N`.
Границы уроков внутри разделов книги приблизительные; при раскадровке урок может сдвинуть их на страницу-две. Значения колонки «Модель» описаны в BOOK.md.
