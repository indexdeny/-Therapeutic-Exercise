For a university project, I explored a practical question: how can dense therapeutic-exercise concepts be presented through movement and interaction?

I built an animated learning experience with SVG figures, short lesson steps, quizzes, captions and local progress tracking. My work covered the concept, requirements, interaction design, learning architecture, content organization and AI-assisted development coordination.

The implementation uses HTML, CSS and JavaScript, with Python tooling and Playwright browser checks. The local candidate preserves 253 lesson pages. Testing distinguishes file availability, runtime behavior and medical/content review; these are separate questions.

The next release must retain clear literature references, audio provenance and accessibility limitations. This is an educational project and does not provide individual treatment advice.

Repository: https://github.com/indexdeny/-Therapeutic-Exercise
