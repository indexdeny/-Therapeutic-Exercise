# Project description — draft

Interactive Therapeutic Exercise is my university project exploring visual learning for complex rehabilitation topics. I designed the learning structure and interactions and coordinated AI-assisted implementation of SVG scenes, step-based lessons, quizzes, captions and browser-local progress.

The full local candidate contains 253 existing lesson pages across 26 units. It uses HTML, CSS and JavaScript in the browser, with Python tooling, Playwright checks and Git LFS media. This is an educational software project, not a clinically validated treatment product. Publication scope and media rights require material-specific review. Verification results must accompany the version being shared.
